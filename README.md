# ⚽ TourneyPro - Soccer Tournament Management System

**TourneyPro** is a web-based application designed to manage soccer tournaments, teams, players, and matches. It provides an intuitive interface for administrators to organize tournaments and for users to explore tournament details, statistics, and more.

---

## 🚀 Features

* **Tournament Management**: Create, update, and delete tournaments.
* **Team Management**: Add teams to tournaments, assign captains, and manage players.
* **Player Management**: Approve players, track goals, and manage red cards.
* **Match Management**: View upcoming and completed matches.
* **Statistics**: View top scorers, red cards by team, and team rankings.
* **Authentication**: Admin login for managing tournaments and teams.
* **Responsive Design**: Optimized for desktop and mobile devices.

## 🛠️ Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v16 or higher)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/tourneypro.git
   cd tourneypro
   ```

2. Install dependencies:

   ```bash
   npm install
   ```
